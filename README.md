## 项目基础介绍

ACE-Step 采用**大模型规划器 + 扩散音频生成**混合架构，先由文本模型规划整首歌曲结构、段落、歌词、曲风、BPM，再通过扩散模型生成带人声、伴奏的完整音频，支持中文、英文、日韩等十多种语言，中文咬字、押韵适配能力突出，是目前开源赛道中最接近 Suno 效果的方案之一。
网上流传的 ACE-Step 整合包，是爱好者封装好的 Windows 一键包，内置可视化 WebUI，解压之后双击启动程序，浏览器自动打开操作面板，省去原版源码复杂的环境部署、模型下载、路径配置，降低上手门槛。**本地运行，不上传音频到第三方云端，生成素材保存在本机，没有次数扣费、没有会员订阅**，这也是它最大的亮点。

## 核心功能能力

### ✅ 文字 Prompt 生成完整歌曲

输入自然语言描述曲风、情绪、配器，例如：温暖民谣吉他、轻快华语流行、悲伤 Rap、古风国风，AI 自动生成歌词、旋律、伴奏与人声演唱，直接输出整首歌曲。

### ✅ 自定义歌词唱歌（歌词驱动）

自己写好完整歌词粘贴进去，选择歌手音色、曲风、BPM、调式，模型自动对齐音节、匹配旋律，实现 “写什么词，AI 唱什么歌”，适合写原创单曲、短视频主题曲、口播配乐。

### ✅ 丰富的创作控制选项

- 支持纯伴奏生成（无人声 BGM），短视频、直播、宣传片配乐首选；
- 局部重绘 Repaint：保留歌曲大部分结构，只重生成某一段副歌 / 主歌，不用整首重跑；
- 换词不改旋律：只修改歌词，保持原有旋律不变，快速改词翻唱；
- 参考音频风格迁移：上传一段参考音乐，让 AI 模仿它的编曲、音色风格；
- 音频分离：自带人声 / 伴奏分轨提取，导出干声方便后期混音；
- LoRA 音色微调：少量参考歌曲即可训练专属歌手音色，打造定制化声线。

### ✅ 导出与素材管理

生成后在线试听，一键导出 WAV、MP3 音频，自动同步生成 LRC 歌词文件；历史生成记录本地保存，支持批量生成、多版本对比挑选，方便创作者批量出歌。

## 硬件运行门槛

- 推荐：NVIDIA 独立显卡，显存≥8G，RTX3060/3090/40 系显卡，生成速度快，一首 3-4 分钟歌曲十几秒～一分钟完成；
- 最低门槛：开启 8bit 量化后，**4G 显存显卡即可运行**；
- 兼容方案：无 N 卡也支持 CPU 模式、Mac M 系列芯片（MPS），但生成速度会明显变慢，适合体验，不适合批量产出。

## 和 SunoAI 的对比

1. SunoAI：云端服务，上手最简单，效果稳定，但是收费、有额度、需要联网，素材受平台协议约束；
2. ACE-Step 整合包：本地离线运行，无次数限制、永久免费、音频本地存储；需要显卡算力，打包 UI 简化部署，自由度更高，支持音色 LoRA 微调、分轨编辑，适合深度创作。

二者不是完全替代关系：快速灵感出样可以继续用 Suno；需要大量生成、本地留存素材、定制音色、离线创作，优先 ACE-Step 本地包。

## 整合包使用简要流程

1. 下载整合包，解压到非中文路径；
2. 双击一键启动脚本，自动拉起 Web 服务；
3. 浏览器自动打开 Gradio 操作界面；
4. 选择模式：文生歌 / 歌词演唱 / 纯伴奏；填写提示词或粘贴歌词；
5. 设置风格、BPM、时长、种子参数，点击生成；
6. 等待渲染完成，试听、导出音频、保存歌词。
